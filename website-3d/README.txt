How to view:

1. Unzip this package.
2. Double-click 启动网页.bat to start the local server and open the page.
3. Or double-click reading-agent-3d.html directly.
4. Three.js is included locally (three.module.js / three.core.js), so it can run offline.
5. Fonts may load from the internet; if they fail, the page still works with system fonts.
4. Wait for the wireframe globe to load to 100%, then click Enter the planet.
5. Drag to rotate the globe, WASD to fly, click buildings to open modules.
